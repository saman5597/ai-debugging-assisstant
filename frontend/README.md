# Frontend

React + TypeScript frontend for AI Root Cause Analyzer.

---

## Features

- Error submission form
- AI analysis display
- Searchable debug history
- Shareable reports
- Responsive UI
- Report routing

---

## Tech Stack

- React
- TypeScript
- Axios
- React Router

---

## Available Scripts

### Install

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
